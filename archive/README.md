# Arsip

Isi folder ini tidak dipakai oleh kode aktif, test, maupun deployment. Disimpan sebagai riwayat.

- `legacy/` — implementasi RBTA, fitur, dan Isolation Forest versi awal (berbasis CSV)
  sebelum refactor ke `src/`.
- `asus/` — konfigurasi, script, dokumentasi, workflow CI, dan test untuk deployment ke
  server ASUS. Target deployment sudah dipindah ke CT Proxmox kampus (`deploy/ct/`).
